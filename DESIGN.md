# Design Write-up

The public service is Spring Boot, while a small private FastAPI service owns the audio model. Spring Boot is used for multipart validation, safe error handling, temporary-file lifecycle management, health reporting, and integration with conventional backend operations. Python is retained only where its audio/ONNX tooling is practical. The selected audEERING six-layer Wav2Vec2 model is publicly downloadable without credentials and returns named age and female/male/child gender logits. Its non-commercial CC BY-NC-SA 4.0 terms make it suitable for this assignment, not unreviewed production use.

Every upload is size limited, decoded by ffmpeg, resampled to mono 16 kHz PCM, and assessed for duration, RMS level, silence, and clipping. Insufficient audio skips model execution. Model confidence is thresholded; child or low-confidence gender is deliberately returned as unknown. The model’s age score is converted to years and mapped only to the requested adult brackets. Age confidence is a conservative, non-calibrated bracket-stability heuristic based on distance from a bracket boundary.

Audio is held only in randomly named temporary files during ffmpeg processing and deleted in finally paths; Python reads the normalized bytes in memory. A loaded model is reused for requests. Warm latency depends on clip length and compute hardware. To support 1,000 concurrent calls, deploy stateless Spring replicas behind a load balancer and a separately autoscaled inference pool with model-per-worker, bounded queues, timeouts, backpressure, and GPU workers/batching where justified. Future work includes calibration using consented representative data and robust voice activity detection.
