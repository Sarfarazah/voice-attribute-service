# Public speech sample guidance

Do not commit personal, private, or copyrighted voice recordings to this repository. For an end-to-end model test, download a short, consented speech clip from a dataset whose terms you have reviewed, such as [Mozilla Common Voice](https://commonvoice.mozilla.org/en/datasets). Common Voice has dataset-specific licence and attribution requirements; follow the current terms for the language/version you use.

Extract one short validated recording to a local path, for example `sample/public-speech.mp3`, without committing it. Then run:

```bash
curl --fail-with-body -X POST http://localhost:8080/analyze \
  -F 'contact_id=123e4567-e89b-12d3-a456-426614174000' \
  -F 'audio=@sample/public-speech.mp3;type=audio/mpeg'
```

The synthetic WAV generated by `scripts/generate-test-wav.py` is suitable only for decoding and quality-gate smoke tests; it is not human speech and must not be used to judge model accuracy.
